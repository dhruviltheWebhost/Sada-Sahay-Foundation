સામાન્ય પ્રશ્નો

મેં ચુકવણી કરી છે પરંતુ Seva ID હજુ મળ્યો નથી.

ચુકવણી કર્યા પછી Transaction ID દાખલ કરો. અમારી ટીમ ચુકવણી ચકાસ્યા બાદ Seva ID આપવામાં આવશે.

મારી ચુકવણીની સ્થિતિ કેવી રીતે તપાસી શકું?

"મારી સેવા" પેજ પર જઈને તમારો Donation Reference દાખલ કરો અને ચુકવણીની સ્થિતિ તપાસો.

Seva ID ક્યાંથી મળશે?

ચુકવણી Confirm થયા પછી તમને Seva ID આપવામાં આવશે. આ ID સાચવી રાખો.

મેં ખોટો Transaction ID દાખલ કર્યો હોય તો?

શક્ય તેટલી વહેલી તકે સેવા ટીમનો સંપર્ક કરો અને સાચી માહિતી આપો.
