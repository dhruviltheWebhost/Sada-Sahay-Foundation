અમારી સેવા

યાત્રિકોની સેવા, અમારી જવાબદારી

સદા સહાય ફાઉન્ડેશન દ્વારા ભાદરવી પૂનમ દરમિયાન અંબાજી તરફ જતા પદયાત્રિકોને માર્ગમાં જરૂરી સહયોગ મળી રહે તે માટે ચા અને નાસ્તા પેકેટ સેવાનું આયોજન કરવામાં આવે છે.

આ સેવા વિસનગર–અંબાજી મુખ્ય માર્ગ પર સતલાસણા નજીક આપવામાં આવશે.

DIGITAL SEVA

તમારો સહયોગ કેવી રીતે કાર્ય કરે છે?

01

સહયોગ પસંદ કરો

તમારી શક્તિ મુજબ સહયોગની રકમ પસંદ કરો.

02

UPI દ્વારા ચુકવણી

QR Code અથવા UPI દ્વારા ચુકવણી કરો.

03

Transaction ID આપો

ચુકવણી કર્યા બાદ મળેલ Transaction ID દાખલ કરો.

04

સેવા ચકાસણી

અમારી ટીમ GPay / UPI Merchant Account માં ચુકવણી ચકાસશે.

05

Seva ID

ચુકવણી Confirm થયા બાદ Seva ID આપવામાં આવશે.

TRUST

પારદર્શિતા અમારી પ્રાથમિકતા

દરેક ઓનલાઈન સહયોગ માટે એક Donation Reference બનાવવામાં આવે છે.

ચુકવણી કર્યા બાદ મળેલ Transaction ID અમારી ટીમ દ્વારા GPay / UPI Merchant Account માં ચકાસવામાં આવે છે.

ચુકવણીની પુષ્ટિ થયા બાદ Seva ID બનાવવામાં આવે છે અને તમે તમારી સેવા Donation Reference અથવા Seva ID દ્વારા ઓનલાઈન તપાસી શકો છો.
