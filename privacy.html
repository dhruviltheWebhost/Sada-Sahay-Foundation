ગોપનીયતા નીતિ

તમારી વ્યક્તિગત માહિતીનો ઉપયોગ કેવી રીતે કરવામાં આવે છે તેની સરળ અને સ્પષ્ટ માહિતી.

છેલ્લે અપડેટ: ઓગસ્ટ ૨૦૨૬

1. અમે કઈ માહિતી એકત્ર કરીએ છીએ?

સેવા સહયોગ આપતી વખતે તમે નામ, મોબાઇલ નંબર, ઈમેલ, સહયોગની રકમ અને ચુકવણી સંબંધિત Transaction ID જેવી માહિતી આપી શકો છો.

2. માહિતીનો ઉપયોગ

આ માહિતીનો ઉપયોગ સેવા સહયોગની નોંધણી, ચુકવણીની ચકાસણી, સેવા ID આપવા અને તમારી સેવા સ્થિતિ દર્શાવવા માટે કરવામાં આવે છે.

3. ચુકવણીની માહિતી

UPI ચુકવણી અમારી પસંદ કરેલી UPI એપ અથવા બેંકિંગ સિસ્ટમ મારફતે કરવામાં આવે છે. તમારી UPI બેંકિંગ વિગતો અથવા UPI PIN અમારી વેબસાઇટ પર દાખલ કરવાની જરૂર નથી.

4. સેવા ID અને Donation Reference

Donation Reference દ્વારા ચુકવણીની સ્થિતિ તપાસી શકાય છે. ચુકવણી Confirm થયા પછી Seva ID આપવામાં આવે છે.

5. જાહેર નામ દર્શાવવું

જો તમે સેવા સહયોગ કરતી વખતે તમારું નામ જાહેર રીતે દર્શાવવાની પસંદગી કરો છો, તો તમારું મર્યાદિત નામ તાજેતરના સેવા સહયોગીઓમાં દર્શાવવામાં આવી શકે છે. અન્યથા તમને Anonymous તરીકે દર્શાવવામાં આવશે.

6. માહિતીની સુરક્ષા

વ્યક્તિગત અને ચુકવણી સંબંધિત માહિતીની સુરક્ષા માટે યોગ્ય તકનીકી અને ઍક્સેસ નિયંત્રણોનો ઉપયોગ કરવામાં આવે છે.

7. તૃતીય પક્ષ સેવાઓ

વેબસાઇટ Firebase/Firestore જેવી તકનીકી સેવાઓનો ઉપયોગ કરી શકે છે. ચુકવણી માટે UPI એપ્લિકેશન અથવા સંબંધિત ચુકવણી સેવા ઉપયોગમાં લેવાઈ શકે છે.

8. સંપર્ક

ગોપનીયતા સંબંધિત પ્રશ્નો માટે અમારી સંપર્ક પેજ દ્વારા અમારો સંપર્ક કરો.

9. નીતિમાં ફેરફાર

જરૂરિયાત અનુસાર આ Privacy Policyમાં ફેરફાર કરવામાં આવી શકે છે. મહત્વપૂર્ણ ફેરફારો વેબસાઇટ પર અપડેટ કરવામાં આવશે.
